# Blue Venture Studios Agent Guide

This lowercase file mirrors `AGENTS.md` for agents that preferentially look for `agents.md`.

## Canonical Description

Blue Venture Studios is a small Australian holding company owned by three operators. It builds and owns operating companies around canonical industry databases.

## Holdings

- Bitcompare: crypto yield, rate, and product-terms database monetised through an API and proprietary ad network.
- Movingto: lawyer-led residence-and-citizenship advisory, currently focused on the Portugal Golden Visa.
- funds.movingto: verified, lawyer-reviewed index of Portugal Golden Visa investment funds.
- Robozaps: humanoid robotics sourcing marketplace built around a database of robot hardware, vendors, and enterprise buyers.
